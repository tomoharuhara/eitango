# 毎日TOEIC英単語テスト

TOEIC に頻出する **1,200 語** を、分野ごとの **24 セット**（1 セット 50 語）に分けて
出題順に出題する学習アプリです。大学生・社会人向けで、しくみは
[大学受験版](../README.md)（システム英単語 2,034 語）とまったく同じです。

## 使い方

**配布用 URL： https://tomoharuhara.github.io/eitango/toeic/**

大学受験版と同じリポジトリ（`tomoharuhara/eitango`）の `toeic/` フォルダとして公開します。
直したときは、このフォルダで変更をコミットして push すれば、1〜2 分で入れ替わります。

```bash
cd "/Volumes/BUFFALO HDD/英単語アプリ" && git add -A && git commit -m "説明" && git push
```

手元で動かす場合は `toeic/index.html` をダブルクリックして開きます。
うまく動かない場合はローカルサーバー経由で開いてください。

```bash
cd "/Volumes/BUFFALO HDD/英単語アプリ" && python3 serve.py
```

起動したら http://localhost:8765/toeic/ を開きます。

## 1 日の流れ（3 回のテスト）

| | テスト | 内容 |
|---|---|---|
| ① | 今日のテスト | 未出題の単語 30 問（出題順の続きから） |
| ② | 前日のテスト（強制） | 前回受けた日と **まったく同じ問題** |
| ③ | 間違い直しテスト | ①②で間違えた問題だけを出題順に再出題 |

- ①が終わるまで②は開けず、②が終わるまで③は開けません（順番は強制）。
- 各テストは **英単語 → 意味を 4 択** と **日本語 → 英単語を 4 択** が半分ずつ（30 問なら 15 問 + 15 問）。
- **選択肢は同じ品詞でそろえます。** 品詞は意味の書き方から判定します（`partOfSpeech`）。
  動詞はさらに「〜」が付くかどうかで分けます。付く語と付かない語が混ざると、形だけで答えが絞れるためです。
  前置詞・接続詞（`via` `despite` `within` など 13 語）は意味が「〜」で始まり動詞と区別できないため、
  `POS_EXCEPTIONS` で名指しして別の区分にしています。区分は 名詞 669 / 動詞「〜」277 / 形容詞 170 /
  動詞（自）45 / 副詞 26 / 前置詞・接続詞 13 の 6 つです。
- 答えを選ぶと、**4 つの選択肢すべてに英単語と意味の両方**が表示されます（`choiceCounterpart`）。
- 答えを選んでも自動では進みません。「次の問題へ」を押して進みます。
- 出題順は常にセット順です（ランダムなのは 4 択のダミー選択肢だけ）。
- テスト終了後に、出題された単語と意味の一覧（単語帳）が ◯✗ 付きで表示されます。
- 1,200 語を **40 日でちょうど一巡**します。1,200 は 30 で割り切れるので、どの日も 30 問です。
- 一巡すると先頭の `recruit` に戻ります。何周しても 1 日目の 30 語は同じです。
- 初日は前日の記録がないため②は自動でスキップされます。
- ①②で 1 問も間違えなかった日は③もスキップされます。

## 復習の記録

- 間違えた単語は「間違えた単語」画面に **間違えた回数つき** で蓄積され、回数の多い順に並びます。
- 「履歴」では日ごとの 3 テストの成績が見られます。

## ログインと記録の保存

メールアドレス + ニックネームで利用します。パスワードはなく、学習データは
**その端末のブラウザ内（localStorage）** に、メールアドレスごとに保存されます。
同じ端末・同じブラウザなら、次回から自動でログインされます。

保存に使うキーの頭は **`toeic.`** です（大学受験版は `vocab.`）。同じサイトに置いても
記録が混ざらないよう、必ず別の名前にしてあります。引き継ぎコードの印も別で（`TT1`／`VT1`）、
取り違えて取り込むことはできません。

**普通の Web ページとして公開してください**（GitHub Pages など）。
Claude のアーティファクトの枠の中では iPhone / iPad の Safari が保存をブロックし、
ログインし直すたびに初日に戻ってしまいます。
起動時に localStorage が使えるか確かめ、使えなければ画面の先頭に赤い警告を出します。

「引き継ぎ」タブで、進み具合を 1 本のコードとして持ち出せます。
別の端末で取り込めば続きから再開でき、記録が消えたときの復元にも使えます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面の入れ物 |
| `app.js` | テスト・復習・記録のロジック |
| `styles.css` | 見た目（ダークモード対応） |
| `words.js` | 単語データ 1,200 語（`data/build.py` が生成するので直接編集しない） |
| `data/words_01.tsv` 〜 `words_24.tsv` | 単語データの元ファイル（`英単語 <TAB> 意味`） |
| `data/build.py` | `words.js` を作るスクリプト |

### 単語データを直したいとき

`data/words_NN.tsv` を直したあと、次のコマンドで `words.js` を作り直してください。

```bash
cd "/Volumes/BUFFALO HDD/英単語アプリ/toeic" && python3 data/build.py
```

`build.py` は作る前に次の 3 つを確かめ、1 つでも外れると何も書かずに止まります。

1. 英単語が重複しないこと（間違い回数は英単語をキーに保存するため）
2. 意味が重複しないこと（選択肢の反対側を意味から引くため）
3. 品詞の区分ごとに 4 語以上あること（4 択を同じ品詞でそろえるため）

意味の書き方で品詞が決まるので、書き換えるときは形をそろえてください。

| 品詞 | 書き方 | 例 |
|---|---|---|
| 他動詞 | 「〜を」「〜に」で始める | `〜を募集する` |
| 自動詞 | 動詞で終える | `通勤する` |
| 形容詞 | 「な」「の」「い」「た」で終える | `効率的な` |
| 副詞 | 「に」「と」で終える | `直ちに` |
| 名詞 | 上のどれにも当てはまらない形 | `応募者` |

この形に収まらない語（`approximately` や `payment` など）は、`data/build.py` と
`app.js` の **両方** の `POS_EXCEPTIONS` に書き足してください。片方だけ直すとずれます。
