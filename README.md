# 毎日英単語テスト

`単語テスト.pdf` に載っている **2,034 語** を、**掲載順**（各ページ 左上→左下 → 右上→右下、1 ページ目から）に出題する学習アプリです。

## 使い方

**配布用 URL： https://tomoharuhara.github.io/eitango/**

GitHub Pages で公開しています（リポジトリ: `tomoharuhara/eitango`）。
生徒に配るときはこの URL を伝えます。パンフレットと QR コードもこの URL です。

直したときは、このフォルダで変更をコミットして push すれば、
1〜2 分で公開中のページも入れ替わります。

```bash
cd "/Volumes/BUFFALO HDD/英単語アプリ"
git add -A && git commit -m "説明" && git push
```

`.gitignore` で公開するファイルを 4 つに絞ってあります（`index.html` `app.js`
`styles.css` `words.js`）。`単語テスト.pdf` や `300問テスト` は公開されません。

以前の公開先（Claude のアーティファクト）は
https://claude.ai/artifact/XW7jddn5Qs3hXNYtAU6vrq に残してあります。
すでに使い始めた生徒は、そちらの「引き継ぎ」タブでコードをコピーし、
新しい URL で取り込めば続きから再開できます。

手元で動かす場合は `index.html` をダブルクリックしてブラウザで開くだけです。
うまく動かない場合はローカルサーバー経由で開いてください。

```bash
cd ~/Downloads/英単語アプリ && python3 serve.py
```

起動したら http://localhost:8765 を開きます。

## 1 日の流れ（3 回のテスト）

| | テスト | 内容 |
|---|---|---|
| ① | 今日のテスト | 未出題の単語 30 問（掲載順の続きから） |
| ② | 前日のテスト（強制） | 前回受けた日と **まったく同じ問題** |
| ③ | 間違い直しテスト | ①②で間違えた問題だけを掲載順に再出題 |

- ①が終わるまで②は開けず、②が終わるまで③は開けません（順番は強制）。
- 各テストは **英単語 → 意味を 4 択** と **日本語 → 英単語を 4 択** が半分ずつ（30 問なら 15 問 + 15 問）。
- **選択肢は同じ品詞でそろえます。** 品詞は意味の書き方から判定します（`partOfSpeech`）。
  動詞はさらに「〜」が付くかどうかで分けます。付く語と付かない語が混ざると、形だけで答えが絞れるためです。
  前置詞・接続詞（`via` `despite` `whereas` など 14 語）は意味が「〜」で始まり動詞と区別できないため、
  `POS_EXCEPTIONS` で名指しして別の区分にしています。区分は 名詞 887 / 動詞「〜」529 / 形容詞 425 /
  動詞（自）142 / 副詞 37 / 前置詞・接続詞 14 の 6 つです。
- 答えを選ぶと、**4 つの選択肢すべてに英単語と意味の両方**が表示されます（`choiceCounterpart`）。
  選ばなかった 3 語もその場で覚えられるようにするためです。選択肢には片側しか保存していないので、
  反対側は `WORD_BY_EN` / `WORD_BY_JA` で文字列から引きます（単語リストに同じ英単語も同じ訳もないため一意に引けます）。
- 答えを選んでも自動では進みません。「次の問題へ」を押して進みます。
- 出題順は常に PDF の掲載順です（ランダムなのは 4 択のダミー選択肢だけ）。
- テスト終了後に、出題された単語と意味の一覧（単語帳）が ◯✗ 付きで表示されます。
- 2,034 語を **68 日でちょうど一巡**します。2,034 は 30 で割り切れないため、一巡の最終日だけ 24 問（12 問 + 12 問）です。
- 一巡すると先頭の `follow` に戻ります。区切りは毎周そろうので、何周しても 1 日目の 30 語は同じです。
- 初日は前日の記録がないため②は自動でスキップされます。
- ①②で 1 問も間違えなかった日は③もスキップされます。

## 復習の記録

- 間違えた単語は「間違えた単語」画面に **間違えた回数つき** で蓄積され、回数の多い順に並びます。
- 「単語一覧」では PDF のページごとに全 2,034 語と意味、各単語の間違い回数を確認できます。
- 「履歴」では日ごとの 3 テストの成績が見られます。

## ログインと記録の保存

メールアドレス + ニックネームで利用します。パスワードはなく、学習データは
**その端末のブラウザ内（localStorage）** に、メールアドレスごとに保存されます。
同じ端末・同じブラウザなら、次回から自動でログインされます。
ログアウトしても記録は消えません。

### 置き場所に注意

**Claude のアーティファクトとして公開すると、アプリは別ドメインの枠の中で動きます。**
この枠の中では、iPhone / iPad の Safari が保存をブロックするため、
ログインし直すたびに初日に戻ってしまいます。枠には `allow-storage-access-by-user-activation`
が付いていないので、保存許可を求めることもできません。

**普通の Web ページとして公開してください**（GitHub Pages など）。
アプリ自身がそのページになるので、どの端末でも保存が確実に効きます。
`index.html` 以下 4 ファイルをそのまま置くだけで動きます。

### 保存できない端末での表示

起動時に localStorage が使えるか確かめ、使えなければ画面の先頭に赤い警告を出します。
テスト中も出します。黙って記録が消えるのがいちばん困るためです。

### 引き継ぎ

「引き継ぎ」タブで、進み具合を 1 本のコードとして持ち出せます。
別の端末で取り込めば続きから再開でき、記録が消えたときの復元にも使えます。
コードには 4 択の中身を含めません（単語と意味と ◯✗ だけ分かればよく、
ダミーの選択肢はその場で作り直せるため）。1 日分でおよそ 100 文字です。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面の入れ物 |
| `app.js` | テスト・復習・記録のロジック |
| `styles.css` | 見た目（ダークモード対応） |
| `words.js` | 単語データ 2,034 語（`data/build.py` が生成するので直接編集しない） |
| `serve.py` | 動作確認用の簡易サーバー |
| `GitHub Pagesでの公開手順.md` | 普通の Web ページとして公開する手順 |
| `data/` | 単語データの元ファイルと生成スクリプト |

`app.js` は上から順に、設定・保存まわり・現在の状態・問題の作成・1 日の進行・画面の土台・共通部品・
各画面・画面の振り分け・起動、の順に並べてあります。保存しているデータの形はファイル冒頭のコメントに
まとめてあるので、localStorage の中身を見るときはそこを参照してください。

### PDF のつづりの誤植について

PDF 側につづりの誤りが 3 語あったため、`data/build.py` の `CORRECTIONS` で正しいつづりに直して出題しています（`data/words_raw.json` は PDF のままです）。

| PDF の表記 | 出題しているつづり | 意味 |
|---|---|---|
| `collage` | **colleague** | 同僚、仲間 |
| `commnist` | **communist** | 共産主義者、共産主義の |
| `occurs` | **occur** | 起こる、生じる |

### 単語データを直したいとき

意味は `data/meanings_01.tsv` 〜 `data/meanings_10.tsv`（`英単語 <TAB> 意味` の形式、PDF 掲載順）に入っています。
直したあと、次のコマンドで `words.js` を作り直してください。

```bash
cd ~/Downloads/英単語アプリ && python3 data/build.py
```
